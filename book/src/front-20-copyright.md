# 关于本书与版本说明

## 一、这本书是什么

**这是一份学习材料，不是 Git 的官方文档，也不是 sourcepack 的使用手册。**

它要做的事只有一件：把 Git 的内部模型讲清楚，让你从"背命令"变成"推命令"。
Git 的权威说明永远在 `git help <command>` 和官方手册里；本书在两者冲突时，
**以 Git 自己的行为为准**——这也是全书的方法论之一。

| 书稿版本 | v1.0（2026-10-13） |

## 二、关于命令与输出

书中的每一段 `$` 命令行输出，都是**在本机真实执行后原样粘贴的**，
没有为了好看而补全、裁剪或编造。但请接受三件事实：

1. **Git 版本不同，输出就可能不同。** 提示文案、缩进、`git status` 的分组方式
   在 2.x 各版本间都改过；本书的输出对应 git 2.39.5；
2. **平台不同，输出也会不同。** 换行符警告、路径分隔符、大小写敏感性、
   文件权限位的显示在 Windows / Linux / macOS 上并不一致；
3. **性能数字只对本机有意义。** 第 10 章那些倍数（比如 delta 压缩带来的体积差）
   是在上述环境里测的。**倍数会变，机制不变**——请关注结论的方向，而不是小数点。

**结论优先于输出**：如果某条命令在你的机器上输出与书中不一致，
先按"机制"判断哪个对，再用 `git help` 或你自己的仓库验证。

## 三、怎么复现这些实验

本书所有标注 `[lab]` 的实验都在一个隔离克隆里做，**不要拿你正在用的仓库做**：

```bash
git clone /path/to/sourcepack /tmp/git-lab
cd /tmp/git-lab
git config user.email lab@example.com
git config user.name Lab
```

`/tmp/git-lab` 是一次性工作区：`reset --hard`、`rebase`、`filter-branch`、
制造"丢失的提交"这些操作都在里面折腾，出任何问题直接删掉重建即可。
标注 `[repo]` 的命令是只读的，在 sourcepack 本体执行也不会改动任何东西。

## 五、勘误与更新

本书是"边做边写"的产物，写错的痕迹我尽量留在正文里（见序言第五条方法论）。
如果你发现错误，有两个去处：

- **最新的源永远在仓库里**：sourcepack 仓库的 `git-course/` 目录是各章正文的源头，
  `book/src/` 存放书名页、本说明与附录。书是这两部分的拼装产物，
  改动请改源文件，重新跑构建脚本即可；
- **行号会漂**：正文里 `文件:行号` 形式的引用对应写作时的代码版本。
  代码继续演进后行号大概率对不上，**请对照函数名一起看**；
- 数字（提交数、tag 数、代码行数）同样是**写作时的快照**，仓库继续提交后必然增长。
